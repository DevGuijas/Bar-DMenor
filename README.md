# Freelance project - ETEC de Embu - São Paulo 

Freelance project made for students at ETEC at Embu - São Paulo.

In this repository you will find a project for an Android application made in Java + Kotlin.

IDE used to code: Android Studio.

Notes: At the moment the project is still messy for organizational reasons, but at the end of the project I will make it as organized as possible.

For more information about the project or questions related to it, please contact g.sampaiodev@gmail.com


# Information related to the project proposal 

* The purpose of the application is to be an app for a fictitious bar for minors, containing non-alcoholic options, etc. This application by default should only contain the main page/view with the menu options, the location page/view with a single fictitious location where this bar would theoretically be and the side bar with the options "Feedback", "Terms and conditions ", "Contact" and "Share" which would not need to be functional, just front-end.

* Even with the proposals established, extra options were added upon approval by the contractors.

* This project was authorized to be made available open-source on Github.
